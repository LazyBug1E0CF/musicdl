## ADDED Requirements

### Requirement: SourcePicker displays 31 platforms in 3 category groups

The SourcePicker component SHALL display 31 music platforms organized into three collapsible category groups:

- **Greater China** (12): QQMusicClient, KugouMusicClient, NeteaseMusicClient, KuwoMusicClient, MiguMusicClient, QianqianMusicClient, StreetVoiceMusicClient, SodaMusicClient, FiveSingMusicClient, BilibiliMusicClient, BodianMusicClient, MOOVMusicClient
- **Global Streaming** (13): YouTubeMusicClient, JooxMusicClient, AppleMusicClient, JamendoMusicClient, SoundCloudMusicClient, DeezerMusicClient, QobuzMusicClient, SpotifyMusicClient, TIDALMusicClient, FMAMusicClient, JioSaavnMusicClient, OpenGameArtMusicClient, SunoMusicClient
- **Aggregators** (6): MP3JuiceMusicClient, TuneHubMusicClient, GDStudioMusicClient, MyFreeMP3MusicClient, JBSouMusicClient, WJHEMusicClient

#### Scenario: User opens search page

- **WHEN** the search page loads and source options are fetched from `/api/v1/sources`
- **THEN** the SourcePicker displays exactly 31 platforms across 3 category groups
- **AND** audiobook/radio platforms (Ximalaya, Lizhi, Qingting, LRTS, ITunes) are not shown
- **AND** unofficial download site platforms are not shown

#### Scenario: All groups expanded by default

- **WHEN** the SourcePicker first renders
- **THEN** all three category groups are expanded
- **AND** users can see all platforms without clicking

### Requirement: Category groups are collapsible

Each category group SHALL have a clickable header that toggles visibility of its platform chips.

#### Scenario: User collapses a group

- **WHEN** user clicks the "Greater China" group header
- **THEN** the platform chips in that group are hidden
- **AND** the header remains visible with an indicator showing the collapsed state

#### Scenario: User re-expands a group

- **WHEN** user clicks a collapsed group header
- **THEN** the platform chips in that group become visible again

#### Scenario: Selection state preserved across collapse

- **WHEN** a group is collapsed while some platforms within it are selected
- **THEN** those platforms remain selected
- **AND** the selection is reflected in search requests

### Requirement: Platform display names render correctly

The SourcePicker SHALL display human-readable names for all 31 platforms. Three platforms with incorrect automatic fallback MUST have explicit label overrides.

#### Scenario: Apple Music displays correctly

- **WHEN** the SourcePicker renders the AppleMusicClient platform
- **THEN** its display label reads "Apple Music" (not "Apple")

#### Scenario: YouTube displays correctly

- **WHEN** the SourcePicker renders the YouTubeMusicClient platform
- **THEN** its display label reads "YouTube" (not "You Tube")

#### Scenario: SoundCloud displays correctly

- **WHEN** the SourcePicker renders the SoundCloudMusicClient platform
- **THEN** its display label reads "SoundCloud" (not "Sound Cloud")

#### Scenario: Other platforms use fallback names

- **WHEN** the SourcePicker renders platforms without explicit labels (e.g., JioSaavnMusicClient, OpenGameArtMusicClient)
- **THEN** their display names are generated by the existing fallback: strip "MusicClient" suffix and insert spaces at camelCase boundaries
- **AND** the results are "Jio Saavn", "Open Game Art" etc.

### Requirement: Existing platform behavior is unchanged

The selection, search, download, and playback behavior SHALL remain unchanged for the 7 originally-visible platforms and work identically for newly-visible platforms.

#### Scenario: Selecting a new platform triggers search

- **WHEN** user selects "Deezer" (previously not shown in picker) and initiates a search
- **THEN** the search request includes "DeezerMusicClient" in the sources array
- **AND** results from Deezer appear alongside results from other selected platforms

#### Scenario: Cookie configuration works for new platforms

- **WHEN** user saves cookies for a newly-visible platform (e.g., YouTube) in Settings
- **THEN** the cookie dot indicator appears on that platform's chip
- **AND** the saved cookies are included in search/download requests for that platform
